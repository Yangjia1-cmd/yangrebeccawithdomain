Copy Text Display Tool

  • Coding | HTML
  • Generative | Type Design
  • Poster Design | Figma

This is a tool that simplifies the process of creating titles for posters, videos, booklets and more. When I was creating posters for my school's Speaker Series I often found it difficult to find interesting typography for my titles. So I created a tool that could generate cool effects and motion graphics to assist my graphic designs.

by using sliders and buttons one can easily change the movement and structure of the type without having to use complex software. This allows more fluid interaction and more control over the final result of the text
